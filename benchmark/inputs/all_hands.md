## A quarter in review

- Two open-source releases hit IBM and HuggingFace blogs: VAKRA and altk-evolve.
- CUGA crossed 700 GitHub stars and shipped inside IBM RPA 30.0.2.
- Five CUGA-powered agents showcased at IBM THINK on Sovereign Core.
- Evolving Agents stood up four OKR streams: Memory, Consistency, RL, Analytics.

## VAKRA benchmark launch

VAKRA — eValuating API and Knowledge Retrieval Agents — went live in late March.
- 1,815 dataset downloads since launch.
- 1,757 leaderboard visits.
- Top 5 on HuggingFace for Question Answering datasets within days.
- Picked up by 10+ third-party blogs, including The Agent Times and Alpha Maven.
- Demo paper accepted to CAIS 2026.

## altk-evolve — on-the-job learning

The agentic toolkit expanded to support agents that learn from real work, one task at a time.
- +8.9 points on goal completion on AppWorld.
- +14.2 points on the hardest tasks on AppWorld.
- Released on IBM Blog and HuggingFace Blog with demos and tutorials.
- Integrating into Bob, Claude Skills, and CUGA.

## CUGA momentum

- 700+ GitHub stars; live adoption metrics at stats.cuga.dev.
- IBM RPA 30.0.2 GA'd with CUGA powering computer-use and UI automation.
- watsonx Assistant for Db2 for Z committed to a CUGA-based ISPF agent for June 19 GA.
- New capability shipped: file ingestion and grounded responses on user-uploaded knowledge.

## Evolving Agents — four OKR streams

- Memory : Drive continuous agent improvement by using agentic memory to learn from past behavior.
- Consistency : Improve reliable task success rates by injecting generated reasoning tips into agent execution. Target +20 pp Pass^5 for React and CUGA agents.
- Reinforcement Learning : Strengthen agentic capabilities while reducing compute cost. Target +8-12 pp on the core eval suite, ≥25% lower inference cost.
- Analytics : Help debug, improve, and maintain agentic systems via AgMentor. Target three developer teams in repeated use.

A cross-org initiative to continuously improve agentic systems so they meet business objectives, SLAs, and enterprise policies.

- Demonstrates agent improvement across quality, consistency, policy conformance, reliability, performance.
